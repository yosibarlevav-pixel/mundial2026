# המגירה – יומן, תזכורות, פוקוס ומאמן

אפליקציית PWA בעברית (RTL), ללא build וללא שרת. כל הנתונים נשמרים ב-localStorage של המכשיר.

הרצה: `npm run dev` ואז `/planner/`, או `python3 -m http.server` מתוך `public/`. ניתן להתקין למסך הבית.

## יכולות
- **המגירה**: הוספה מהירה בטקסט או בקול (he-IL), זיהוי "מחר 17:30", באנר משימות שפספסת, "השבוע" / "מתישהו" עם גרירה, וכפתור "קשב, תסדר לי את זה" ששובץ אוטומטית בזמנים פנויים.
- **יומן**: ציר זמן יומי, פס שבוע עם נקודות קטגוריה והחלקה בין שבועות, משימות חוזרות, פערי זמן פנוי עם + להוספה, בחירת תאריך.
- **קשב (מאמן)**: 6 נושאים (תכנון, ריכוז, דחיינות, עומס, רגש, הרגלים) עם פעולות מהירות והיסטוריית שיחות. תשובות מבוססות כללים (ללא AI חיצוני).
- **פוקוס**: פומודורו עם הפסקות, סבבים, צלילי רקע (גשם/גלים/רעש לבן) וספירת סשנים.
- **תזכורות**: התראות דפדפן בזמן המשימה או X דקות לפני (פועל כשהאפליקציה פתוחה/מותקנת; תזכורות כשהיא סגורה לגמרי דורשות שרת Push).
- **הגדרות**: פרופיל, שעות השכמה/שינה, צבע ראשי, צלילים ורטט, ייבוא/ייצוא ‎.ics‎, גיבוי JSON, מחיקת נתונים.
